# The Kerfield Arms: website concept

A static, single-page concept site for The Kerfield Arms, 16 Grove Lane, Camberwell. It covers the pub, the bar and dining room, recognition, the à la carte menu as HTML, groups and private dining with an enquiry form, and visiting information.

This is a demo. There is no CMS, database or payment system, and the enquiry form only shows a confirmation in the browser, with a link that opens the details in an email. Reservations, gift vouchers and Instagram go to the pub's existing pages.

## Structure

```
index.html            the page
css/styles.css        styles (day and evening palettes)
js/main.js            navigation, day/evening switch, open-now status, gallery viewer, enquiry form
fonts/                Libre Caslon Display, Libre Caslon Text and Work Sans (SIL Open Font License)
images/               web-sized photography and logo (generated by the script below)
scripts/              image download and resize
.github/workflows/    GitHub Pages deployment
```

## Images

`scripts/fetch-images.sh` downloads the logo, the Michelin badge and the photography (Joe Howard) from the pub's current site, then `scripts/resize-images.py` writes web sizes to `images/` (800/1600px JPEGs, 2400px for the hero). Originals go to `images/src/`, which is ignored by git.

Requires Python 3 with Pillow (`pip install pillow`).

```
./scripts/fetch-images.sh
```

If the resized images aren't committed, the Pages workflow runs this script during the build.

## Preview locally

```
./scripts/fetch-images.sh
python3 -m http.server 8000
```

Then open http://localhost:8000. Use a local server rather than opening the file directly: the logo is drawn as a CSS mask, and browsers block that on `file://`.

## Deploy to GitHub Pages

1. In the repository, go to **Settings → Pages** and set **Source** to **GitHub Actions**.
2. Push, or run the **Deploy to GitHub Pages** workflow from the Actions tab.

All paths are relative, so the site works from `https://<user>.github.io/<repo>/`.

## Day and evening

The page follows London time: daylight colours from 6am, and an evening palette lit by lanterns from 6pm, when dinner service starts. Visitors can switch between them with the toggle in the header, and their choice is remembered.

## Content notes

- Menu: À la carte, 8 October 2026. Dishes and prices are as printed (no £ sign). The full wine and drinks list and the Sunday menu link to the pub's PDFs.
- Opening hours drive the "open now" line, worked out in London time.
- The page is marked `noindex` so the concept doesn't compete with the pub's own site in search results.
